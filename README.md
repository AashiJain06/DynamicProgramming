# Dynamic Programming in Java 🚀

A collection of classic **Dynamic Programming (DP)** problems implemented in **Java**.  
This repository contains solutions to popular DP problems from platforms like **LeetCode** and **GeeksforGeeks**, covering recursion, memoization, tabulation, and space optimization approaches.

---

## 📌 Repository Overview

This repository is created to:

- Practice Dynamic Programming concepts
- Improve problem-solving skills
- Understand different DP patterns
- Maintain optimized Java solutions for interview preparation

---

## 🛠️ Tech Stack

- **Language:** Java
- **IDE:** IntelliJ IDEA / VS Code
- **Concepts Used:**
  - Recursion
  - Memoization
  - Bottom-Up DP
  - Space Optimization
  - Greedy + DP
  - Arrays & Strings
